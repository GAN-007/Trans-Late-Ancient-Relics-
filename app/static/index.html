SYSTEM

        
What the platform does

        
ESHB is a reversible modern bridge. Middle Egyptian mode is historical language analysis. Those layers remain deliberately separate.

        

        
Privacy defaults

        
    
          
  • Camera frames are not stored by the application.
    • 
          
  • Microphone speech recognition is handled by the browser/platform implementation; only the resulting transcript is sent for translation.
    • 
          
  • Translation history is saved only when an authenticated user explicitly requests it.
    • 
          
  • AI-generated dictionary entries remain proposals until reviewed.
